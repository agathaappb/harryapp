# Harry app

Este é um projeto para estudos. :shipit:
Nesta primeira branch compenta o estudo da base do mvvm
Esta primeira funcionalidade é bem simple, apenas exibe a imagem de uma das casas de Hogwarts, simulando o chapéu seletor. 
Aqui nesta primeira versão temos somente uma lista mockada com as casas e uma função do use case que faz a lógica para sortear a casa. 
Tudo o mais simples possível. :shipit:
